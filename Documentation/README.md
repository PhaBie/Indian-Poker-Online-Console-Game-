## แนวทางการพัฒนาและส่งมอบงาน

1. ศึกษาคู่มือพัฒนาและแบ่งงานเพื่อเข้าใจภาพรวมสถาปัตยกรรม (Core, Domain, Network, Infrastructure, Client)
2. ตรวจสอบข้อกำหนดใน Contracts ก่อนแก้ไขการสื่อสารหรือกติกาของเกม
3. ปฏิบัติตามหลัก TDD (Test-Driven Development): เขียนหรือปรับปรุง Test ให้ครอบคลุมก่อนเสมอ
4. ก่อนส่งมอบงานหรือเปิด Pull Request ต้องผ่านการตรวจด้วย `bun run lint`, `bunx tsc --noEmit` และ `bun test` ทุกครั้ง

สถานะปัจจุบัน: ระบบเกม Indian Poker รองรับการเล่นทั้งแบบ Local และ Online ผ่าน WebSocket มีชุดทดสอบครอบคลุมการทำงาน 571 รายการผ่านการทดสอบ 100%
