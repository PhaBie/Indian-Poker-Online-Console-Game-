# เอกสารสำหรับเริ่มพัฒนา

เอกสารชุดนี้จัดทำจากโครงสร้าง Source, Test และการตั้งค่าใน repository เพื่อใช้ส่งต่องานให้ทีมพัฒนา

| เอกสาร | ใช้สำหรับ |
| --- | --- |
| [คู่มือแบ่งงานและเชื่อมต่อระบบ](DEVELOPMENT_HANDOFF.md) | ดูว่าแต่ละส่วนต้องพัฒนาไฟล์ใด รับผิดชอบอะไร และส่งงานให้ใคร |
| [สรุปการเปลี่ยนแปลงและข้อความ commit/PR](CHANGE_SUMMARY.md) | ทบทวนสิ่งที่เปลี่ยนจาก PR #9 และนำข้อความไปใช้ประกอบ commit หรือ PR |

## เริ่มจากอะไร

1. อ่านคู่มือแบ่งงาน แล้วตกลงผู้รับผิดชอบแต่ละส่วน โดยคนหนึ่งรับได้หลายส่วน
2. เปิดไฟล์ Source คู่กับ Test ที่ระบุในตาราง เลือกพัฒนาทีละพฤติกรรม
3. ให้ผู้รับผิดชอบสองฝั่งตกลงรูปแบบข้อมูลก่อนแก้ shared types หรือ signature ที่ใช้ร่วมกัน
4. ส่ง PR พร้อมระบุสิ่งที่ทำ ผลตรวจ และสิ่งที่ยังรอส่วนอื่น

ไฟล์ `core_functions_for_tdd.txt` เป็นรายการออกแบบเดิม มีชื่อและ signature บางส่วนไม่ตรงกับโค้ดปัจจุบัน เช่น `determineWinners` ซึ่งปัจจุบันใช้ `getWinners` จึงควรใช้ Source และ Test ปัจจุบันประกอบคู่มือนี้เป็นหลัก หากพบข้อขัดแย้งให้ตกลงกติกาก่อนแก้ทั้งสองส่วน

สถานะปัจจุบันคือโครงเริ่มต้นพร้อมชุดทดสอบและเครื่องมือตรวจมาตรฐาน ฟังก์ชันส่วนใหญ่ยังเป็น Stub และยังไม่ใช่เกมที่เล่นได้ครบวงจร
