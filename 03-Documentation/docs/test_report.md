# Test Report (รายงานสรุปผลการทดสอบระบบ)

เอกสารสรุปผลการทดสอบระบบ **Indian Poker Online (Teen Patti)** ทั้งในระดับชุดทดสอบอัตโนมัติ (Automated Unit Tests) และการทดสอบการทำงานจริงด้วยตนเอง (Manual Acceptance Tests)

---

## 1. ผลการทดสอบอัตโนมัติ (Automated Tests Summary)

โครงการใช้ตัวดำเนินการทดสอบในตัวของ Bun (`bun test`) ซึ่งดำเนินการทดสอบครอบคลุมทั้ง Core Logic, Domain Models, Schema Validation, Network Socket และ State Management

### ข้อมูลสถิติการทดสอบ:

- **จำนวนชุดทดสอบทั้งหมด:** 536 ชุดทดสอบ (536 passed, 0 failed)
- **จำนวนการตรวจสอบ (Expect Calls):** 1,715 การตรวจสอบ
- **จำนวนไฟล์ทดสอบ:** 41 ไฟล์
- **ระยะเวลาการทดสอบรวม:** ~570 มิลลิวินาที

```text
Ran 536 tests across 41 files. [573.00ms]
536 pass
0 fail
1715 expect() calls
```

### การจำแนกหมวดหมู่การทดสอบ:

1. **Core Game Logic (`02-Tests/server/core/`):** ตรวจสอบการสร้างสำรับ, การสับไพ่, การแจกไพ่, การเปรียบเทียบลำดับไพ่ 6 รูปแบบ และการคำนวณเงินกองกลาง
2. **Domain Models (`02-Tests/server/domain/`):** ตรวจสอบวัฏจักรสถานะของ `Player`, `Room`, `RoomManager` และ `GameState` ทั้ง Happy Path, Unhappy Path และ Boundary Cases (เช่น การจ่ายเงินเกินขอบเขต, เงินติดลบ)
3. **Data Schemas & Validators (`02-Tests/server/core/`):** ตรวจสอบความถูกต้องของ Input Payload ด้วย Zod
4. **Client & Network (`02-Tests/client/`, `02-Tests/shared/`):** ตรวจสอบการจัดการ Socket และ DTOs
