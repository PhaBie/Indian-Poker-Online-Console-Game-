# กติกาและวิธีการเล่น (Game Rules)

## รูปแบบการเล่นในแต่ละรอบเกม

1. สร้างห้อง / เข้าห้อง (รองรับ 2-4 คน)
2. ทุกคนลงขัน (Boot) เข้าสู่ Pot (กองกลาง)
3. ระบบแจกไพ่คว่ำหน้าคนละ 3 ใบ (ทุกคนจะเริ่มที่สถานะ Blind)
4. วนเทิร์นเพื่อลงเดิมพัน โดยเลือกว่าจะเป็น Blind หรือ Seen
5. ผู้เล่นสามารถเลือกคำสั่งต่างๆ เช่น ตาม (Call), เพิ่มเดิมพัน (Raise/Bet), หมอบ (Fold)
6. เมื่อเหลือผู้เล่น 2 คน สามารถเลือก SHOW เพื่อเปิดไพ่วัดผล (หรือหากมีคนหมอบจนเหลือคนเดียว คนนั้นจะชนะทันที)
7. ผู้ชนะรับเงินทั้งหมดใน Pot แล้วเริ่มรอบใหม่

## สถานะ Blind และ Seen

- **Blind:** ผู้เล่นที่ยังไม่เปิดดูไพ่ของตัวเอง จะจ่ายเงินเดิมพันในราคาปกติ
- **Seen:** ผู้เล่นที่เปิดดูไพ่ของตัวเองแล้ว จะต้องจ่ายเงินเดิมพันเป็น 2 เท่าของผู้เล่น Blind ตลอดรอบนั้น

_เทคนิค:_ Blind สามารถใช้เกทับเพื่อกดดันผู้เล่นที่ Seen ได้ เพราะ Seen ต้องจ่ายเงินมากกว่าเสมอ

## การลงเดิมพัน

- **CALL:** ลงเงินตามจำนวนเดิมพันขั้นต่ำในรอบนั้น
- **RAISE / BET:** เพิ่มจำนวนเงินเดิมพัน ทำให้ผู้เล่นคนอื่นต้องลงเงินเพิ่มตาม
- **SEEN:** เปิดดูไพ่ของตัวเอง เปลี่ยนสถานะเป็น Seen
- **FOLD:** หมอบและยอมแพ้ในรอบนั้น

## การขอ SHOW (เปิดไพ่วัดผล)

- สามารถขอ SHOW ได้เมื่อเหลือผู้เล่นที่ยังไม่หมอบอยู่ 2 คนสุดท้ายเท่านั้น
- **เงื่อนไขสำคัญ:** ผู้เล่นที่เป็น Seen ไม่สามารถขอ SHOW ใส่ผู้เล่นที่ยังเป็น Blind ได้
- **การเสมอ:** ถ้าคะแนนไพ่ของทั้งสองฝ่ายเท่ากัน คนที่เป็นฝ่ายขอ SHOW จะถือว่าเป็นผู้แพ้

## การเรียงลำดับของไพ่ (Hand Rankings)

เรียงลำดับจากใหญ่ที่สุดไปเล็กที่สุด ดังนี้:

1. **ตอง (Trail / Set):** ไพ่ที่มีแต้มเหมือนกัน 3 ใบ เช่น A-A-A (ใหญ่สุด) หรือ 7-7-7
2. **เรียงสี (Pure Sequence):** ไพ่ที่เรียงลำดับแต้มและมีดอกเดียวกัน เช่น A-2-3 (ใหญ่ที่สุด) หรือ 10-J-Q
3. **เรียงธรรมดา (Sequence / Run):** ไพ่ที่เรียงลำดับแต้มแต่คนละดอก เช่น 4-5-6
4. **สี (Color / Flush):** ไพ่ที่มีดอกเดียวกันทั้งหมดแต่แต้มไม่เรียงกัน เช่น A-7-10 (ดอกโพดำทั้งหมด)
5. **คู่ (Pair):** ไพ่ที่มีแต้มเหมือนกัน 2 ใบ เช่น K-K-5
6. **ไพ่สูง (High Card):** ถ้าไม่มีเข้าข่ายข้างต้น จะใช้แต้มของไพ่ที่สูงที่สุดตัดสิน (A คือสูงสุด, 2 คือต่ำสุด)

## เป้าหมายของเกม

เป้าหมายหลักคือชนะและรับเงินทั้งหมดใน Pot
สามารถชนะได้ 2 วิธี:

1. ทำให้ผู้เล่นคนอื่น FOLD จนเหลือคุณเป็นคนสุดท้าย
2. อยู่รอดจนเหลือ 2 คน แล้วทำการ SHOW หากคุณมีไพ่ที่ลำดับสูงกว่า คุณคือผู้ชนะ
