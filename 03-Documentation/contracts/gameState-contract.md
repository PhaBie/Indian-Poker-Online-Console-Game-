# ข้อกำหนดระบบ GameState (ฉบับเข้าใจง่าย)

เอกสารนี้คือกติกาของ GameState ที่ทั้งโค้ดจริงและชุดทดสอบต้องทำงานตรงกัน

**หลักการที่ใช้ทั้งระบบ:** ถ้าเมธอดไหนโยน Error ต้องไม่มีอะไรเปลี่ยนเลย ทั้งเงิน ไพ่ และสถานะผู้เล่น (Atomicity)

---

## 1. เริ่มเกม `startGame()`

**ต้องมีก่อนเรียก:** ผู้เล่นอย่างน้อย 2 คน

**สิ่งที่เกิดขึ้น:**

- หักชิปทุกคนตาม `bootAmount` (กำหนดเองได้ตอนสร้าง GameState) แล้วรวมเข้า `pot`
- แจกไพ่คนละ 3 ใบ ไม่ซ้ำกัน (ไพ่ในมือ + ไพ่ในกอง = 52 ใบ)
- ทุกคนเป็น `ACTIVE` และ `isBlind = true`

**ถ้าเงินไม่พอ:** ถ้ามีใครมีชิปไม่พอจ่าย Boot ให้โยน `InsufficientChipsError` ทันที โดยไม่หักเงินและไม่แจกไพ่ใคร

---

## 2. เปลี่ยนตาและเปลี่ยนดีลเลอร์

**แยกหน้าที่ชัดเจน:** การกระทำอย่าง BET, CALL, RAISE **ไม่เลื่อนตาเอง** Server/Room ต้องเช็คก่อนว่ารอบจบหรือยัง ถ้ายังมีคนเล่นต่อค่อยเรียก `nextTurn()`

**`nextTurn()`**

- เลื่อน `currentPlayerIndex` ไปหาคน `ACTIVE` คนถัดไป วนกลับต้นแถวได้ และข้ามคน `FOLDED`, `DISCONNECTED`, `WAITING` ได้หลายคนติดกัน
- ถ้าไม่มี `ACTIVE` เหลือเลย → โยน `PlayerStateError`
- ถ้าเหลือ `ACTIVE` คนเดียว → ไม่เลื่อนตา (ค้างไว้รอจบรอบ)

**`rotateDealer()`**

- ย้าย Dealer ไปผู้เล่นคนถัดไป วนกลับคนแรกได้

**ทั้งสองเมธอดต้องไม่เปลี่ยนเงินหรือไพ่ของใคร**

---

## 3. Timeout และ Disconnect

**`autoFoldTimeout()`**

- บังคับหมอบทันที
- **ผู้เรียกต้องเช็คเองว่า** Timer ที่ดังยังเป็นของตาปัจจุบันอยู่ (เมธอดนี้ไม่รู้ว่าเป็น Timer ของตาเก่าหรือไม่)
- ไม่เลื่อนตาเอง (Server ต้องจัดการต่อถ้ารอบยังไม่จบ)
- ถ้าหลังหมอบแล้วเหลือ `ACTIVE` คนเดียว → จ่าย Pot ให้คนนั้นทันทีและตั้ง Pot เป็น 0

**`handlePlayerDisconnect(playerId)`**

- เปลี่ยนเป็น `DISCONNECTED` โดยไม่คืนเงินเดิมพัน และไม่กระทบเงินคนอื่น
- หลุดตอน**ไม่ใช่ตาตัวเอง** → ไม่เลื่อนตา
- หลุดตอน**เป็นตาตัวเอง** → เลื่อนตาอัตโนมัติ (หรือจบรอบถ้าเหลือ 1 คน)
- หลุดซ้ำ (เป็น `DISCONNECTED` อยู่แล้ว) → ไม่ทำอะไรซ้ำ ไม่จ่ายเงินซ้ำ
- ถ้า ID ไม่มีในระบบ → โยน `GameError('...', 'PLAYER_NOT_FOUND')`

---

## 4. ทำ Action `processAction(playerId, action, amount)`

**ต้องมีก่อนเรียก:** เป็นตาของ `playerId` และผู้เล่นต้องเป็น `ACTIVE` (ถ้าเป็น `WAITING` หรือ `DISCONNECTED` ให้ปฏิเสธ)

### ช่วงเงินของ BET / CALL / RAISE

กำหนดให้ **S = currentStake**

| Action    | Blind (ยังไม่ดูไพ่)  | Seen (ดูไพ่แล้ว)      |
| --------- | -------------------- | --------------------- |
| **BET**   | จ่าย S ถึง 2S        | จ่าย 2S ถึง 4S        |
| **CALL**  | จ่าย S               | จ่าย 2S               |
| **RAISE** | จ่ายมากกว่า S ถึง 2S | จ่ายมากกว่า 2S ถึง 4S |

**Stake ใหม่ (หลัง BET/RAISE):** Blind = ยอดที่จ่าย, Seen = ครึ่งหนึ่งของยอดที่จ่าย

**ข้อจำกัดทศนิยม:** ถ้า Seen จ่ายแล้วหารสองได้ทศนิยม ต้องปฏิเสธ (โยน Error) เพราะ Stake ต้องเป็นจำนวนเต็มเสมอ

### ตรวจสอบค่าตัวเลข

ต้องโยน `INVALID_AMOUNT` **ก่อนเปลี่ยน State ใดๆ** เมื่อ amount เป็น:

- ติดลบ, 0, ทศนิยม
- `NaN`, `±Infinity`
- ไม่ส่งมา หรือเป็น String
- เกิน `Number.MAX_SAFE_INTEGER` หรือเมื่อบวกกับ Pot แล้วเกินขีดจำกัด

### SEEN (ขอดูไพ่)

- ไม่ใช่การจบตา
- เรียกซ้ำไม่เสียเงินเพิ่ม
- การเดิมพันครั้งต่อไปจะคิดเรท Seen (2 เท่า)

---

## 5. ขอ SHOW (`processAction` ด้วย `SHOW`)

**ต้องมีก่อนเรียก:** ผู้เล่นที่ยังเล่นอยู่ (ไม่นับ FOLDED/DISCONNECTED) ต้องเหลือแค่ 2 คน แม้ใน Array จะมีคนมากกว่านั้นก็ขอได้ ถ้า `ACTIVE` มี 2 คน

**ค่าใช้จ่าย:**

| ผู้ขอ | คู่แข่ง  | ผล                                    |
| ----- | -------- | ------------------------------------- |
| Blind | ใครก็ได้ | หัก 1 เท่าของ Stake                   |
| Seen  | Seen     | หัก 2 เท่าของ Stake                   |
| Seen  | Blind    | **ปฏิเสธ** (โยน `InvalidActionError`) |

**ถ้าไพ่เสมอหรือต่ำกว่า:** ผู้ขอ SHOW **แพ้ทันที** และถูกเปลี่ยนเป็น `FOLDED` เฉพาะรอบนี้ (รีเซ็ตเมื่อเริ่มรอบใหม่)

**ถ้าเงินไม่พอจ่ายค่า SHOW:** ไม่หักเงิน State คงเดิม

---

## 6. ผู้ชนะและการจบรอบ

### ผลลัพธ์ `RoundResult` (แบ่งตาม `winReason`)

| winReason              | เกิดเมื่อ                                                                 | `winningHand`          | `exposedCards`                      |
| ---------------------- | ------------------------------------------------------------------------- | ---------------------- | ----------------------------------- |
| `SHOW`                 | ขอ SHOW สำเร็จ ผู้ขอไพ่เหนือกว่า                                          | แต้มจริง (`HandRank`)  | ไพ่ของทั้งสองคน                     |
| `SHOW_TIE`             | ขอ SHOW แล้วแต้มเสมอทุกใบ **ผู้ที่ไม่ได้ขอ SHOW ชนะ** (ตามกติกา Pagat)    | แต้มจริงของผู้ชนะ      | ไพ่ของทั้งสองคน                     |
| `LAST_PLAYER_STANDING` | เหลือ `ACTIVE` คนเดียว (คนอื่นหมอบหรือออกห้อง) รับ Pot โดยไม่ต้องเทียบไพ่ | `null`                 | `{}` (ว่าง เพื่อรักษาความลับของไพ่) |
| `FORCED_SHOWDOWN`      | บังคับตัดสินหลายคนด้วย `evaluateWinner()`                                 | แต้มจริงของผู้ชนะคนแรก | ไพ่ของทุกคนที่ยัง `ACTIVE`          |

### หน้าที่ของแต่ละเมธอด

- **`checkLastManStanding()`**: ดูเฉพาะคน `ACTIVE` ถ้าเหลือ 1 คนคืนคนนั้น ถ้าเหลือ 0 คน มากกว่า 1 คน หรือ Array ว่าง ให้คืน `null` และไม่เปลี่ยน State
- **`endGame()`**: โอน `pot` ให้ผู้ชนะคนเดียว แล้วคืน `RoundResult`
- **`evaluateWinner()`**: โอนเงินใน Pot ให้คนไพ่ชนะ แล้วคืน `RoundResult` ที่มี `winReason: 'FORCED_SHOWDOWN'`

### กฎสำคัญ

- คนที่เป็น `FOLDED`, `WAITING`, `DISCONNECTED` จะไม่ได้รางวัลเลย ต่อให้ถือไพ่ดีที่สุด
- เรียกจบรอบซ้ำ ต้องไม่จ่ายเงินซ้ำ

## 7. ไพ่เสมอและการแบ่ง Pot

### การ SHOW เสมอ (ตามกติกา Teen Patti / Pagat)

- ใช้ได้เมื่อเหลือ `ACTIVE` แค่ 2 คน
- ถ้า `compareHands()` ได้ผลเท่ากัน → ผู้ขอ SHOW หมอบ (`player.fold()`) และบันทึก `isTie: true` ใน `pendingShow` ผลคือ `winReason: 'SHOW_TIE'`
- มีผู้ชนะคนเดียว รับ Pot ทั้งหมด ไม่มีการแบ่ง

### การแบ่ง Pot ใน `evaluateWinner`

- ถ้าเป็น Forced Showdown หรือมีผู้ถือแต้มสูงสุดเท่ากันหลายคน ให้แบ่ง Pot เท่าๆ กัน และแจกเศษชิปตามลำดับผู้ชนะที่ส่งเข้า `calculateSplitPot()`
- เศษชิปยึดตามกลไกของ `calculateSplitPot` ใน Core โดยชุดทดสอบจะระบุตัวเลขและลำดับผู้ชนะชัดเจน

### ความปลอดภัยของชิป

- **Chip Invariant:** ผลรวมชิปทุกคน + Pot **ก่อนจ่ายรางวัล** ต้องเท่ากับ **หลังจ่ายรางวัล** เสมอ
- **ป้องกันชิปเกินขีดจำกัด:** ถ้าการจ่ายให้ผู้ชนะคนใดทำให้ชิปเกิน `MAX_SAFE_INTEGER` ให้โยน `GameError(INVALID_AMOUNT)` โดยตรวจก่อนจ่าย ป้องกันการจ่ายแค่บางส่วน (Atomic Settlement) และเงินใน Pot ต้องอยู่ครบ

## 8. Sideshow / DUEL

**ชื่อเรียก:** ในระบบ (Domain/Network/State) ใช้ `SIDESHOW` แต่หน้าจอ UI แสดงเป็น `DUEL` และเรียกใช้ผ่าน `processAction()` เท่านั้น

### เงื่อนไขการขอ

- ต้องมี `ACTIVE` มากกว่า 2 คน
- `ACTIVE` ทุกคนต้องดูไพ่แล้ว (`isBlind === false`)
- ต้องเป็นตาของผู้ขอ (`challenger`) และมีชิปพอจ่าย `currentStake * 2`
- เป้าหมาย (`target`) คือผู้เล่นคนก่อนหน้าที่ยัง `ACTIVE`

### การตอบรับ

เป้าหมายเลือกได้ 2 อย่าง:

- **`ACCEPT_SIDESHOW`** → เทียบไพ่ระหว่างผู้ขอกับเป้าหมาย คนไพ่ต่ำกว่า `FOLDED` ถ้าเสมอกันทุกใบ **ผู้ขอหมอบ** (ตามกติกา Teen Patti)
- **`REJECT_SIDESHOW`** → ไม่มีใครหมอบ ไม่เปิดไพ่ และบันทึก `lastSideshowNotice` เป็น `DECLINED`

### ความลับของไพ่ (Card Privacy)

ข้อมูลไพ่ในการดวลส่งผ่าน Network Payload ให้แค่ผู้ขอและเป้าหมายเท่านั้น ผู้เล่นคนที่สามและผู้ชมได้รับ `sideshowResult: null` ไม่มีไพ่รั่วไหล

### หลัง Sideshow

เกมไปต่อที่ผู้เล่นคนถัดไป ยกเว้นถ้าผลดวลทำให้เหลือคนเดียว ให้จบรอบและจ่าย Pot ทันที
